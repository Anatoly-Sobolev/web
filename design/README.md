# Прототипы проекта

Файл `prototypes.drawio` содержит прототипы сайта «Справочник единиц измерения».

В документе 9 страниц: три экрана в вариантах Mobile, Tablet и Desktop.

Открыть файл можно в браузере на [diagrams.net](https://app.diagrams.net/) через команду **File → Open From → Device**.

## Состав экранов

1. Главная страница и конвертер.
2. Каталог единиц измерения.
3. Карточка единицы измерения.

Поиск и выбор категории сделаны элементами каталога, а не отдельными страницами.

Прототипы показывают структуру страниц и расположение основных блоков. Цвета, типографика и детальное оформление определяются в проекте Figma для лабораторной №2.
