# Прототипы проекта

Файл `prototypes.drawio` содержит структурные прототипы сайта «Мера — справочник единиц измерения» (ЛР1).
Файл создаётся сценарием `scripts/build_prototypes.js` (`node scripts/build_prototypes.js`).

Открыть файл: https://app.diagrams.net/ → **Файл → Открыть с → Устройство**.

## Страницы файла (11)

0. Карта сайта и переходы — страницы, стрелки с подписями действий, ссылки на все прототипы.
1–3. Главная и конвертер — Mobile (360 px), Tablet (768 px), Desktop (1440 px).
4–6. Каталог единиц — Mobile, Tablet, Desktop.
7–9. Карточка единицы — Mobile, Tablet, Desktop.
10. Состояния интерфейса — результат и ошибка конвертации, пустой поиск, единица не найдена, БД недоступна, мобильное меню.

Элементы навигации содержат ссылки на страницы документа: в режиме просмотра щелчок открывает целевой прототип.
Цвета и типографика определяются в проекте Figma (ЛР2).
