# Дизайн спецификация сайта Справочник единиц измерения

## Проект Figma

[Мера — справочник единиц измерения](https://www.figma.com/design/sCt5ju49i6680hCjosaYHh/)

Страница «Макеты»: девять кадров (три экрана × Mobile, Tablet, Desktop), кадры состояний «ошибка ввода», «ничего не найдено», «единица не найдена» и «Меню / Mobile». Страница «Компоненты»: 9 иконок и 11 наборов компонентов. В файле 19 цветовых и 24 текстовых стиля.

## Концепция

Спокойный учебный интерфейс с акцентом на точность, понятность и быстрый доступ к конвертеру. Визуальный стиль основан на светлом фоне, тёмно-синей навигации и голубом акценте.

## Цвета

Фактическая палитра файла (цветовые стили группы «Цвет»), совпадает с переменными site/css/style.css.

- Шапка: `#172554`.
- Акцент: `#2563EB`, наведение `#1D4ED8`.
- Светлый акцент: `#EFF6FF`.
- Основной текст: `#1F2937`.
- Вторичный текст: `#6B7280`; текст подвала `#4B5563`.
- Фон страницы: `#F5F5F5`.
- Поверхность карточек: `#FFFFFF`.
- Границы и подвал: `#E5E7EB`; шапка таблицы `#F9FAFB`; бейдж `#F3F4F6`.
- Ошибка: `#DC2626`, фон `#FEF2F2`, текст `#991B1B`.
- Успех: фон `#F0FDF4`, граница `#BBF7D0`, подпись `#166534`, значение `#15803D`.

## Типографика

- Шрифт: Inter.
- Заголовок страницы: 32/40, Semibold.
- Заголовок секции: 24/32, Semibold.
- Заголовок карточки: 18/26, Medium.
- Основной текст: 16/24, Regular.
- Подписи: 14/20, Regular.

## Сетка и разрешения

- Mobile: ширина 360 px, минимальная видимая область 760 px, поля 16 px, одна колонка. Длинная страница может быть выше и прокручиваться.
- Tablet: фрейм шириной 768 px, поля 24 px, до двух колонок.
- Desktop: фрейм шириной 1440 px (высота по содержимому, не меньше 900 px), поля 64 px, до трёх колонок.

## Компоненты Figma

- Header, Footer: Breakpoint = Desktop, Tablet, Mobile.
- Button: Primary (Default, Hover, Disabled), Secondary.
- Text field: Default, Focus, Error, Disabled.
- Select: Default, Focus.
- Search bar: Empty, Filled.
- Conversion result: Success, Error.
- Category card: Vertical, Horizontal.
- Unit row: Default, Hover; Unit card (mobile).
- Badge: Neutral, Accent.

## Страницы

Для каждого из трёх экранов необходимо создать варианты Mobile, Tablet и Desktop. Фреймы следует назвать по схеме `Экран / Разрешение`, например `Главная / Desktop`.

## Интерактивный прототип

- Логотип ведёт на главную страницу.
- Пункт «Каталог» открывает каталог единиц.
- Строка каталога открывает карточку единицы.
- Ссылка «Назад» и бейдж категории ведут в каталог, «Открыть в конвертере» — на главную.
- Кнопка «☰» открывает кадр «Меню / Mobile».
- Поле «Значение» открывает кадр ошибки ввода, поле поиска — кадр пустого результата.
- Стартовые точки потоков: Desktop, Tablet, Mobile.
