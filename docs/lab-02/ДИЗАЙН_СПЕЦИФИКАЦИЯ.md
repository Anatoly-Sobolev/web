# Дизайн спецификация сайта Справочник единиц измерения

## Проект Figma

[Мера — справочник единиц измерения](https://www.figma.com/design/sCt5ju49i6680hCjosaYHh/)

В проекте находится девять редактируемых фреймов: три экрана в вариантах Mobile, Tablet и Desktop.

## Концепция

Спокойный учебный интерфейс с акцентом на точность, понятность и быстрый доступ к конвертеру. Визуальный стиль основан на светлом фоне, тёмно-синей навигации и голубом акценте.

## Цвета

- Основной тёмный: `#172554`.
- Акцентный: `#2563EB`.
- Светлый акцент: `#DBEAFE`.
- Основной текст: `#0F172A`.
- Вторичный текст: `#475569`.
- Фон страницы: `#F8FAFC`.
- Поверхность карточек: `#FFFFFF`.
- Границы: `#CBD5E1`.
- Ошибка: `#DC2626`.
- Успех: `#16A34A`.

## Типографика

- Шрифт: Inter.
- Заголовок страницы: 32/40, Semibold.
- Заголовок секции: 24/32, Semibold.
- Заголовок карточки: 18/26, Medium.
- Основной текст: 16/24, Regular.
- Подписи: 14/20, Regular.

## Сетка и разрешения

- Mobile: фрейм 360 × 760 px, поля 16 px, одна колонка.
- Tablet: фрейм 768 × 900 px, поля 32 px, до двух колонок.
- Desktop: фрейм 1280 × 900 px, поля 40 px, до четырёх колонок.

## Компоненты Figma

- Header: Desktop, Tablet, Mobile.
- Button: Primary, Secondary, Ghost; состояния Default, Hover, Disabled.
- Text field: Default, Focus, Error, Disabled.
- Select: Default, Open, Selected.
- Unit row: Default, Hover.
- Search bar: Default, Filled.
- Conversion result: Default, Success, Error.
- Footer.

## Страницы

Для каждого из трёх экранов необходимо создать варианты Mobile, Tablet и Desktop. Фреймы следует назвать по схеме `Экран / Разрешение`, например `Главная / Desktop`.

## Интерактивный прототип

- Логотип ведёт на главную страницу.
- Пункт «Каталог» открывает каталог единиц.
- Строка каталога открывает карточку единицы.
- Поиск и фильтр изменяют содержимое каталога.
- Основная кнопка конвертера отображает состояние с результатом.
