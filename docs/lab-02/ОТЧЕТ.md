# Лабораторная работа №2 Разработка визуального дизайна сайта в Figma

## Цель работы

Разработать визуальный дизайн адаптивного сайта «Мера — справочник единиц измерения» на основе прототипов лабораторной работы №1.

## Проект Figma

[Открыть проект «Мера — справочник единиц измерения»](https://www.figma.com/design/sCt5ju49i6680hCjosaYHh/)

## Разработанные экраны

1. Главная страница с конвертером.
2. Каталог единиц измерения с поиском и фильтром.
3. Карточка единицы измерения.

Каждый экран подготовлен в трёх вариантах:

- Mobile — 360 × 760 px;
- Tablet — 768 × 900 px;
- Desktop — 1280 × 900 px.

## Визуальное решение

Использован простой светлый интерфейс без декоративных элементов. Основной шрифт — Inter. Шапка выполнена в тёмно-синем цвете `#172554`, основной акцент — синий `#2563EB`. Поля, кнопки и блоки имеют одинаковое оформление на всех экранах.

## Адаптивность

На мобильной версии элементы конвертера и каталога располагаются вертикально. На планшете и компьютере доступная ширина используется для горизонтального размещения элементов и таблицы каталога.

## Результат проверки

- создано девять фреймов;
- названия фреймов соответствуют схеме «Экран / Разрешение»;
- применён единый визуальный стиль;
- размеры основных фреймов приведены к заданным разрешениям;
- содержимое соответствует прототипам лабораторной работы №1.

## Вывод

Подготовлен адаптивный визуальный дизайн трёх основных страниц сайта. Макеты можно использовать как основу для HTML/CSS-вёрстки.
