# Лабораторная работа №3. Вёрстка веб-сайта по готовому дизайну

Полный отчёт: `Отчёт_ЛР3_Соболев.docx`, снимки: `screenshots/`. Исходный код: каталог `site/`.

**Технологии:** HTML5, CSS3 (Grid, Flexbox, переменные, медиазапросы 1024 и 600 px), JavaScript.

**Структура:** `index.html`, `catalog.html`, `unit.html`, общие `css/style.css`, `js/app.js`, `img/icons.svg`; данные `js/units-data.js` генерируются из `data/units.json` (12 категорий, 140 единиц).

**Интерактивность:** конвертер с проверкой ввода и формулой; поиск и фильтр каталога со счётчиком и пустым состоянием; карточка единицы по `?id=` с формулами пересчёта и состоянием «не найдена»; мобильное меню.

**Проверка:** Edge (Chromium) при ширине 1440, 768 и 360 px; примеры: 100 °C = 212 °F, 1 миля = 1,609344 км, поиск «метр» + «Длина» — 7 единиц. Firefox/Safari и валидатор W3C не использовались.

**Вывод:** вёрстка всех страниц адаптивна и соответствует макету Figma; стили и сценарий переиспользуются PHP-приложением.
