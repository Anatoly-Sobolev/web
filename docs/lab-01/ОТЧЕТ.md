# Лабораторная работа №1 Создание прототипов веб-сайта

## Цель работы

Разработать структурные прототипы адаптивного веб-сайта «Справочник единиц измерения» до начала визуального дизайна и программной реализации.

## Постановка задачи

Необходимо определить перечень страниц сайта, расположить основные интерфейсные блоки и подготовить варианты каждой страницы для мобильного, планшетного и настольного разрешения.

## Разработанные страницы

1. Главная страница с конвертером.
2. Каталог единиц измерения.
3. Карточка единицы измерения.

Поиск и фильтрация по категории выполняются прямо в каталоге.

## Навигация

С главной страницы пользователь может перейти в каталог или сразу выполнить конвертацию. В каталоге доступны поиск и фильтр по категории. Выбор строки открывает карточку конкретной единицы.

## Адаптация интерфейса

- Mobile: блоки располагаются в одну колонку, навигация сокращается, поля конвертера размещаются вертикально.
- Tablet: сохраняется компактная навигация, карточки могут располагаться в две колонки.
- Desktop: используется широкая область контента, полная навигация, таблицы и горизонтальное расположение элементов конвертера.

## Результат

Подготовлен файл `design/prototypes.drawio`, содержащий 9 прототипов: три экрана в трёх разрешениях.

## Вывод

Сформирована структура сайта и определены основные пользовательские переходы. Прототипы готовы для разработки визуального дизайна в Figma.
