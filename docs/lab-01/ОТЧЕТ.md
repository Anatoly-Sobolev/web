# Лабораторная работа №1. Создание прототипов веб-сайта

Полный отчёт: `Отчёт_ЛР1_Соболев.docx`, снимки: `screenshots/`.

**Цель:** разработать структурные прототипы всех страниц сайта «Мера» до визуального дизайна и программирования.

**Страницы:** главная с конвертером; каталог с поиском и фильтром по категории; карточка единицы (`unit?id=…`).

**Состояния:** результат конвертации, ошибка ввода, ничего не найдено, единица не найдена (404), БД недоступна (503), мобильное меню.

**Результат:** `design/prototypes.drawio` — 11 страниц: карта сайта с подписанными переходами, 9 прототипов (3 страницы × Mobile 360 / Tablet 768 / Desktop 1440 px), страница состояний. Навигационные элементы связаны ссылками между страницами.

**Адаптация:** Mobile — одна колонка, меню «☰», каталог карточками; Tablet — «Из/В» в строку, две колонки категорий, таблица; Desktop — форма в одну строку, три колонки категорий и соотношений.

**Вывод:** структура сайта и переходы определены; прототипы использованы для дизайна в Figma.
