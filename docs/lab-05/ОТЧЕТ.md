# Лабораторная работа №5. Вывод данных из базы данных на веб-странице

Полный отчёт: `Отчёт_ЛР5_Соболев.docx`, снимки: `screenshots/`.

**БД:** `categories` (6 записей) и `units` (41 запись, FK `category_id`, коэффициент `factor` и сдвиг `offset_si`); `database/schema.sql`, `database/seed.sql`.

**Приложение:** `app/public/index.php`, `catalog.php`, `unit.php`; SQL-запросы — `app/src/UnitRepository.php` (подготовленные запросы PDO); шаблоны — `app/templates/`.

**Обработка ошибок:** пустой поиск, категория без единиц, пустой справочник, неизвестная единица (404), недоступная БД (503, запись в журнал).

**Проверка:** добавление записи «Астрономическая единица» через psql изменило каталог (11 → 12 единиц длины) без правки кода; при остановленном PostgreSQL `/catalog.php` вернул 503.
