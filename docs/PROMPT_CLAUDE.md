## Требования к выполнению работ

Ориентируйся на полные формулировки задания в PDF. Ключевые критерии:

- **ЛР1:** определить страницы и состояния интерфейса; подготовить для каждой страницы структурный прототип Mobile, Tablet и Desktop; показать основные блоки и понятные пользовательские переходы; сохранить исходный редактируемый файл draw.io.
- **ЛР2:** перенести согласованную структуру в доступный редактируемый проект Figma; оформить цвета, типографику и повторно используемые элементы; создать все страницы в трёх разрешениях; связать основные страницы интерактивными переходами в Prototype. Проверь текущую ссылку и состояние файла; если проект недоступен, создай максимально воспроизводимый результат из доступных средств и точно опиши ограничение, не заявляя о создании Figma-фреймов без подтверждения.
- **ЛР3:** сверстать страницы по дизайну, обеспечить адаптивность на телефоне, планшете и компьютере, реализовать предусмотренные интерактивные элементы, организовать общие стили и проверить в браузере. Сейчас HTML-страницы есть, однако отдельно проверь, работают ли конвертер, поиск, фильтр и навигация; статические демонстрационные значения не выдавай за работающую функциональность.
- **ЛР4:** настроить обязательный стек NGINX + PHP/PHP-FPM + MySQL или PostgreSQL, виртуальный хост, доступность приложения и подключение к БД. Подготовить повторяемую конфигурацию проекта (например, Docker Compose), если это поддерживается доступной средой. Зафиксировать фактические версии и команды запуска. Не утверждай, что сервер запущен или проверен, если его запуск и запросы не подтверждены.
- **ЛР5:** создать схему базы данных для справочника, начальные данные, PHP-подключение и SQL-запросы; выводить данные на страницах динамически; обработать пустую выборку и ошибку подключения; показать, что изменение данных БД отражается в браузере.

Если Docker или нужные приложения отсутствуют, сначала проверь доступные локальные инструменты. Не устанавливай системные программы и не меняй глобальные настройки Windows без необходимости. Подготовь конфигурацию, исходники, инструкции и максимально возможную проверку доступными средствами; явно перечисли только реальные препятствия.
