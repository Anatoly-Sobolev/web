# План подготовки проекта по веб-технологиям

## Выбранная тема

**Тема 12 — Справочник единиц измерения.**

Итогом всех лабораторных будет один сайт: каталог единиц измерения с поиском, просмотром по категориям и конвертером величин.

## Что установить

VS Code достаточно как редактора, но для запуска сайта и базы данных нужны дополнительные программы.

Обязательно:

1. **Figma Desktop** — дизайн всех страниц и интерактивный прототип для лабораторной №2.
2. **draw.io Desktop** — структурные прототипы для лабораторной №1. Можно использовать веб-версию, но приложение удобнее для хранения файла проекта.
3. **Docker Desktop** — запуск обязательного стека NGINX + PHP-FPM + MySQL без отдельной ручной установки каждого сервиса.
4. **Git** — контроль версий. Если команды Git уже работают в терминале VS Code, дополнительно устанавливать его не нужно.

Полезно, но необязательно:

- расширения VS Code: PHP Intelephense, Docker, EditorConfig;
- DBeaver Community — удобный графический просмотр таблиц и данных MySQL;
- браузер Chrome или Edge для проверки адаптивности через DevTools.

Перед использованием Docker Desktop нужно убедиться, что в Windows включены виртуализация и WSL 2. Если преподаватель не разрешает Docker, вместо него придётся отдельно настраивать NGINX, PHP и MySQL. XAMPP не подходит как основной вариант, потому что обычно использует Apache, а по заданию требуется NGINX.

## Какие проекты и файлы создать

В этом репозитории создать следующие части:

```text
web/
├── design/
│   ├── prototypes.drawio
│   └── exports/
├── docs/
│   ├── lab-01/
│   └── lab-02/
├── app/
│   ├── public/
│   ├── src/
│   └── config/
├── database/
│   ├── schema.sql
│   └── seed.sql
├── docker/
│   └── nginx/
├── compose.yaml
└── README.md
```

Отдельные рабочие проекты:

- **draw.io:** один файл `design/prototypes.drawio` со всеми страницами в трёх размерах;
- **Figma:** один проект «Справочник единиц измерения», также со всеми страницами и компонентами;
- **VS Code:** открыть корень этого Git-репозитория;
- **Docker Compose:** один набор контейнеров NGINX, PHP-FPM и MySQL;
- **DBeaver:** одно подключение к MySQL из Docker.

## План выполнения

### Шаг 1. Уточнить тему

Согласовать с преподавателем тему №12 и возможность использовать Docker Desktop. До подтверждения тему не усложнять дополнительными функциями.

### Шаг 2. Закрыть лабораторную №1

Определить страницы:

- главная страница с конвертером;
- каталог единиц;
- карточка единицы измерения.

Поиск и фильтр по категории находятся внутри каталога и не требуют отдельных страниц.

Для каждой страницы сделать в draw.io три прототипа: mobile, tablet и desktop. Показать навигацию и основные переходы. Подготовить отчёт со скриншотами.

### Шаг 3. Закрыть лабораторную №2

Создать в Figma:

- цветовые и текстовые стили;
- компоненты кнопок, полей ввода, карточек и навигации;
- дизайн всех страниц в трёх разрешениях;
- интерактивные переходы между основными экранами.

Дизайн лучше собирать непосредственно в Figma. Claude или Codex можно использовать для концепции, структуры, текстов, цветовой схемы и референсного макета. Автоматический импорт HTML или изображения в Figma обычно требует исправлений и не заменяет редактируемые компоненты. Финальный учебный макет должен оставаться полноценным проектом Figma.

### Шаг 4. Подготовить основу для следующих лабораторных

После сдачи первых двух работ:

1. Создать HTML/CSS/JavaScript-вёрстку в `app/public`.
2. Настроить через Docker Compose NGINX, PHP-FPM и MySQL.
3. Создать таблицы `categories` и `units`.
4. Добавить тестовые единицы измерения в `seed.sql`.
5. Подключить PHP к MySQL через PDO.
6. Реализовать каталог, поиск, фильтрацию и конвертацию.

## Ближайший результат

Сначала должны быть готовы два файла/проекта:

1. `design/prototypes.drawio` — полностью закрывает основу лабораторной №1.
2. Проект Figma «Справочник единиц измерения» — полностью закрывает основу лабораторной №2.

Писать PHP и проектировать базу данных можно после утверждения прототипов и дизайна, чтобы не переделывать страницы дважды.
